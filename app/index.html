How it works

  1. Reads the labels printed on the diagram (OCR).
  2. Follows each leader line to the part it names.
  3. Segments that part with Segment Anything.
  4. Redraws it for touch: bold outlines, textures instead of colours, braille labels, 3 mm spacing (BANA guidelines).
  5. Checks the result and lets you fix any label before printing.

Everything runs on your computer. The first run downloads about 90 MB of models, which your browser then caches.
