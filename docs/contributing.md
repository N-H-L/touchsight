# Contributing

Thank you for considering a contribution. The practical details live in the repository: see [CONTRIBUTING.md](https://github.com/mrhunsaker/touchsight-NG/blob/main/CONTRIBUTING.md), [CODE_STYLE.md](https://github.com/mrhunsaker/touchsight-NG/blob/main/CODE_STYLE.md), [CODE_OF_CONDUCT.md](https://github.com/mrhunsaker/touchsight-NG/blob/main/CODE_OF_CONDUCT.md) and [CHANGES.md](https://github.com/mrhunsaker/touchsight-NG/blob/main/CHANGES.md).

Quick summary:

1. Fork, create a branch, make the change.
2. Run the evaluation harness (`npm run eval`, `node scripts/recall.mjs`) and include the before/after numbers for anything that touches tracing, segmentation or layout.
3. Follow the style described in CODE_STYLE.md (ES modules, no semicolons, single quotes, 2-space indent, comments that explain *why*).
4. Open a pull request with a short description and, where relevant, screenshots or evaluation output.
5. Note that this project licenses code under GPL-3.0-or-later.
