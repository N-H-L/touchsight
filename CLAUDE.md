## Hackathon workflow
- Project records live in `docs/hackathon/`:
  - BRIEF.md: rules and sources
  - IDEAS.md: research and shortlist
  - PLAN.md: approved direction
  - STATE.md: progress and next action
  - EVIDENCE.md: verified claims
- Read STATE.md first.
- **Hard deadline: Sun Oct 11 23:59 EDT = Mon Oct 12 11:59 SGT.** All code must be committed inside the hacking window (after Fri Oct 9 20:45 EDT). Do not import any code from other local projects.
- The repo must become public on GitHub before submission. That needs user approval.
- No paid APIs or billable resources without user approval. Keep secrets in `.env` (gitignored).
- README must cite all models, datasets, and libraries, and disclose the AI tools used (Claude Code).
- Update STATE.md at each milestone and before any handoff.
